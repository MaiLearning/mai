# Воркфлоу агента

Разобранные сценарии. Правила — в инструкциях сервера; здесь — как они
выглядят на практике.

## Найти материал внутри курса

Оглавление отдаёт дерево текстом: одна строка на узел, id в скобках.

```
курс «Rust с нуля» [3f2a9c14-…] · узлов 12 · ресурсов 5
  Модуль 1 · Основы [dir 9a1c7e30-…]
    Лекция 1. Что такое Rust [res 4b7e11d2-… theory 1758901234]
    Задачи к лекции 1 [res 77c0a9b4-… task 1758901300]
  Модуль 2 · Ownership [dir c3d5e6f7-…]
```

Разбор строки: отступ — глубина, `dir` / `res` — вид узла, UUID — идентификатор
для следующего вызова, после `typeKey` идёт `upd:` — дата изменения.

Дальше по найденному `resourceId`:

1. `mai_get_resource` с `resourceId` — карточка. Полная не нужна, пока
   содержимое не читаешь.
2. `mai_get_content` с тем же `resourceId` — только если содержимое нужно целиком.

## Сузить выборку

Оглавление по умолчанию показывает 2 уровня и до 200 узлов. Дальше — точечно:

- `depth: 1` — только верхний уровень, чтобы увидеть состав модулей;
- `rootId: <id директории>` — поддерево конкретного модуля;
- `typeKeys: ["theory"]` — только лекции, без задач;
- `rootId: <id ресурса>` — путь от корня до этого узла, если забыл, где он лежит;
- `maxNodes` — поднять потолок, если узлов больше, чем влезло.

Если вывод обрезан, в последней строке стоит подсказка — сужай выборку, а не
читай остальное подряд.

## Найти место в тексте

Не скачивай содержимое целиком ради одного факта.

1. `mai_search` с `query` и `courseId` — совпадения придут с `resourceId`.
2. По совпадению определи ресурс, дальше `mai_get_content` — но уже точечно.

Поиск работает по именам узлов и по содержимому: у теории — по тексту, у задач
и кода — по JSON. Результат — список совпадений, а не тело ресурса.

## Прочитать содержимое

`mai_get_content` отдаёт `format`:

- `text` — читаемый текст, самый дешёвый вариант; по умолчанию;
- `json` — исходный документ целиком, без потерь. Нужен, когда важна
  структура, а не читаемость.

Формат задаёт `typeKey` ресурса: теория приходит как документ редактора, задачи
— как JSON со списком задач и прогрессом.

Если содержимого у ресурса ещё нет, `mai_get_content` вернёт `not found` — это
не ошибка вызова, а отсутствие данных. Пустой документ появляется в БД только
после первой записи через редактор.
