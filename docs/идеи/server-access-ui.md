# Доступ к серверу: UI-механизмы

Статус: идея · Зависимости: [HTTP-сервер](../roadmap/http-server.md) (P2)

## Зачем

UI-механизмы работы с HTTP-сервером:

- Генерация токенов доступа.
- «Вежливый стук»: внешний клиент (например, ИИ) желает подключиться —
  уведомляет пользователя и присылает запрос с определённым id. Пользователь
  видит плашку вида «Неизвестный клиент с таким-то id желает подключиться —
  разрешить?» и даёт или отказывает в доступе.
