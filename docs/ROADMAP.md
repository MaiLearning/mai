# ROADMAP — дорожная карта Mai

Индекс пунктов: порядок, приоритеты, ссылки на заметки. Заметка в
`roadmap/` есть = пункт принят в работу; сырые идеи живут в `идеи/`
(по файлу на идею) или строкой без ссылки. Путь пункта: сырая строка →
идея (`идеи/`) → заметка-заготовка (`roadmap/`) → проработка → работа →
готово.

Формат пункта: `- [ ] P1 — [Название](./roadmap/<slug>.md) — кратко`.
Приоритет: P1 — сейчас, P2 — следующий этап, P3 — когда-нибудь.
Статусы в заметках: заготовка | проработана | в работе | готово | отклонено.
Пункт готов: `[x]` здесь + статус `готово` в заметке.
