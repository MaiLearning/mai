# External Plugin API — средства для внешних плагинов

Статус: заготовка · Приоритет: P3 · Зависимости: [External-плагины](./external-plugins.md)

## Зачем

Набор средств, через которые внешние плагины получают доступ к
приложению. Кандидаты namespaces:

- **StorageAPI** — хранилище данных плагина (управление данными
  на Rust-стороне);
- **CourseAPI** — управление курсами: создание, удаление, изменение;
- **ResourceAPI** — работа с ресурсами;
- **StructureAPI** — работа со структурой курса;
- и далее по доменам.

Не путать с [Plugin Gateway](./plugin-gateway.md) (плагин ↔ плагин):
это направление «плагин → приложение».
