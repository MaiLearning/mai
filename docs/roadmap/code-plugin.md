## Прогресс

- Пути интерпретаторов вынесены в пользовательские настройки плагина
  (`plugin/internal-code`, поля `pythonPath` / `javascriptPath`): определение
  `codeSettingsDefinition` регистрируется в `init_plugins`, форма — общая
  `SettingsSchemaForm`. Бэкенд (`CodeService::resolve_runtime`) читает тот же
  пункт через `SettingsService` вместо `app_kv` (`code-plugin/runtimes`);
  пустая строка = рантайм не настроен.
- Добавлена поддержка Rust: третий язык урока (`CodeLanguageSchema`,
  `LANGUAGE_LABEL`, подсветка `@codemirror/lang-rust`) и поле настроек
  `rustcPath` (путь до компилятора `rustc`, зеркало на бэкенде —
  `runtime_field("rust") == "rustcPath"`). В отличие от Python/JavaScript,
  Rust — компилируемый язык: `executor::run_rust` пишет `main.rs`, компилирует
  его `rustc` (`--edition 2021 -o main`) во временном каталоге и лишь при
  успешной компиляции запускает полученный бинарник; таймаут (10 с) и лимит
  каптуры вывода (64 KB) действуют на каждую стадию отдельно. Ошибка/таймаут
  компиляции возвращаются как обычный результат запуска (ненулевой
  `exitCode`), а не ошибка сервиса — для UI это неудачная проверка шага, а не
  сломанный рантайм. Диагностика `rustc` (ошибки и warnings) всегда идёт в
  `stderr` результата — на успешной компиляции склеивается со `stderr`
  программы.
