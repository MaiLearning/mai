# External-плагины — механизм внешних плагинов

Статус: заготовка · Приоритет: P3 · Зависимости: [Plugin Gateway](./plugin-gateway.md),
[External Plugin API](./external-plugin-api.md)

## Зачем

Механизм внешних плагинов: пишутся через SDK (mai-lib, mai-cli, mai-dev),
устанавливаются пользователем в рантайме — в отличие от internal-плагинов,
которые являются частью билда (см. `src/plugins/PLUGINS.md`).

Доступ внешних плагинов к приложению — через
[External Plugin API](./external-plugin-api.md) (StorageAPI, CourseAPI
и т.д.); взаимодействие плагинов между собой — через
[Plugin Gateway](./plugin-gateway.md).
