# Badge

- **Слой:** foundation
- **Файлы:** `badge.tsx` / `badge.style.ts` / `badge.stories.tsx`

## Назначение

Компактная метка статуса/категории: `soft` — tint-подложка с текстом
роли, `solid` — насыщенная заливка с контрастным текстом. Цвет — через
`intent` (tone) и модель steps/contrastText.

## Когда использовать

- Небольшая визуальная маркировка (статус, категория, количество).

## Когда НЕ использовать

- Сообщение пользователю с текстом и иконкой — `Alert` (primitive).

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `tone` | `IntentName` | `'neutral'` | Смысловая роль бейджа |
| `variant` | `soft \| solid` | `'soft'` | Приглушённая подложка / насыщенная заливка |
| `children` | `ReactNode` | — | Содержимое метки |
| `className` | `string` | — | Для позиционирования извне |

## Зависимости

Импортирует `badge.style.ts` и `base/theme` (тип `IntentName`). Из
других слоёв ничего не использует.
