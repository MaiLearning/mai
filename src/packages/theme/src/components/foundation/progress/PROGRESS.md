# Progress

- **Слой:** foundation
- **Файлы:** `progress.tsx` / `progress.style.ts` / `progress.stories.tsx`

## Назначение

Полоса прогресса с измеримой степенью выполнения. Семантика через
`role="progressbar"` + `aria-valuenow/min/max`.

## Когда использовать

- Задача с известной степенью выполнения (проценты, шаги, этапы).

## Когда НЕ использовать

- Процесс без измеримой степени — `Spinner` (foundation).

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `percent` | `number` (обязателен) | — | Степень 0..100 (значения за диапазоном нормируются) |
| `aria-label` | `string` | `'Прогресс'` | Подпись прогрессбара |

## Зависимости

Импортирует `progress.style.ts`. Из других слоёв ничего не использует.
