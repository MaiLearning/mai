# foundation/

Самый фундаментальный слой UI — **базис системы**.

Его роль не в том, чтобы содержать «самые маленькие компоненты», а в том,
чтобы дать базовое правило или особое свойство — универсальный механизм,
на котором строится остальной интерфейс.

Foundation **не знает и не решает пользовательскую задачу**. Он не несёт
семантики приложения: не понимает «действия», «выбора», «ввода». Его дело —
механика организации и представления интерфейса (раскладка, типографика,
скролл, обёртки, базовые визуальные примитивы).

### Пример - Stack

```tsx
<Stack gap="md">
  ...
</Stack>
```

Суть и назначение `Stack` — выступать для **вертикального или
горизонтального расположения элементов** ( в реализации включает `direction` + `gap` + `align`).
Он ничего не знает о том, что внутри: это чистая инфраструктура раскладки.
Живёт в `foundation/stack/` (`stack.tsx` + `stack.style.ts` + стори).

## Как это связано с остальными слоями

- **`foundation/` ← база для всего.** `primitive/`, `pattern/` и `component/`
  (внешние пакеты) строятся на его механизмах.
- **`primitive/`** добавляет семантику: тот же расклад может лечь в основу
  `Button`, `Card`, `List`. Примитив знает о пользовательских действиях —
  foundation нет.
- **`pattern/`** комбинирует элементы фонда и/или примитивы в устойчивую
  структуру со своим API.
- **`component/`** (внешние пакеты) собирает фонд, примитивы и паттерны
  в законченные продукты.

Сам foundation ничего не импортирует из `primitive/`, `pattern/` и тем более
из `component/`. Граф импортов во всей модели ацикличен.

## Что сюда относится

Перенесено из `src/ui/` (миграция идёт по группам одного назначения):

- раскладка и обёртки: `Stack`, `Flex`, `Box`;
- типографика и представление: `Text`, `Heading`;
- индикация: `Spinner`, `Progress`, `Badge`;
- поверхность: `Card`;
- прокрутка: `ScrollArea`.

> **Иконки уехали в отдельный пакет `@mai/icons`** (контейнер `Icon` +
> каталог глифов на базе lucide-react). Тема потребляет его напрямую;
> своих глифов в foundation больше нет.

Ещё кандидаты (не перенесены — следующие batch'и миграции):

- кандидатов на перенос в foundation из текущего `src/ui/` не осталось;
  механизмы всплывающих панелей (`usePopover`, `popover.style`)
  отнесены
  к слою `primitive/` (см. PRIMITIVE.md).

Точный состав фиксируется при переносе компонентов из `src/ui/`.
У каждого перенесённого компонента — собственная заметка `*.md`
в его директории (назначение, когда использовать, примеры).
