# Grid

- **Слой:** foundation
- **Файлы:** `grid.tsx` / `grid.style.ts` / `grid.stories.tsx` / `grid.test.ts`

## Назначение

Колоночная раскладка. Специализация `Box`: под капотом тот же нормализованный
блок, к которому добавлены сетка, шаблон колонок, зазор и выравнивание
элементов внутри треков.

Отличие от `Flex` и `Stack` — не в направлении, а в том, что элементы попадают
в **общие колонки**. В одномерной раскладке каждая строка живёт сама по себе:
элементы выравниваются только внутри неё. В сетке заголовок может занять три
колонки, панель — четыре строки, а выравнивание по колонкам общее для всех
строк сразу. Ради этих двух вещей грид и нужен; всё остальное в нём —
обычная механика.

## Когда использовать

- Элементы должны попадать в колонки, общие для всех строк: заголовок
  секции, панель сбоку, карточки одинаковой ширины в каталоге.
- Колонки неравные и их ширины заданы осмысленно: «иконка — подпись —
  действие» (`18px 1fr auto`).
- Каталог элементов сам занимает столько места, сколько есть: карточки
  переносятся без заданного числа колонок (`min`).

## Когда НЕ использовать

- Элементы просто стоят рядом или столбцом — `Flex` (полный контроль) или
  `Stack` (ось и зазор). Грид — не более мощный заменитель одномерной
  раскладки, а другой механизм.
- Нужно отцентрировать единственного потомка: `display: grid; place-items:
  center` в разметке репозитория встречается 10 раз, и это не сетка, а
  центрирование. Его умеет `Flex`.
- Нужен только вертикальный ритм: `display: grid; gap: X` без колонок
  встречается 3 раза и является `Stack` с лишним `display`.
- Нужны области по именам, явное размещение элементов (`grid-area`,
  `grid-column`, `grid-row`), `subgrid` или ручной `grid-auto-flow`: таких
  мест в репозитории нет, поэтому в API их нет.
- Нужен **потолок** адаптивного числа колонок (1 на узкой области, 2 на
  средней, 3 на широкой) — оставьте лестницу в своём стиле. `min` задаёт
  плотность, а не потолок: при `minmax(280px, 1fr)` и зазоре 16px на области
  1200px поместится 4 колонки (`4*280 + 48 = 1168`), даже если в проекте на
  этой ширине положено показывать три. Два таких места в репозитории —
  `CourseLibrary.style.ts` и `StatusPicker.style.ts`.

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `columns` | `number \| string` | — | Число равных колонок (`3` → `repeat(3, 1fr)`) или шаблон треков дословно (`'1fr auto 1fr auto'`) |
| `min` | `string` | — | Минимальная ширина трека: `repeat(auto-fit, minmax(min, 1fr))`, колонок столько, сколько влезет |
| `gap` | `SpacingKey \| number` | — | Зазор между строками **и** колонками: ключ каталога `theme.spacing` или число базовых шагов |
| `align` | `start \| end \| center \| stretch \| baseline` | `stretch` | Выравнивание элементов по поперечной оси внутри треков (`align-items`) |
| `justify` | `start \| end \| center \| stretch` | `stretch` | Выравнивание элементов по главной оси внутри треков (`justify-items`) |
| `as` | `div \| section \| main \| article \| header \| footer \| aside \| nav` | `'div'` | Семантический тег корня |

Плюс все атрибуты `<div>` (кроме `align` — он переопределён грид-пропсом).

## Ловушка: `justify` здесь не то же, что в `Flex`

Имя совпадает, смысл — нет:

| | `Flex` | `Grid` |
|---|---|---|
| `justify` | `justify-content`: распределяет **элементы** по главной оси, отсюда `space-between`, `space-evenly` | `justify-items`: выравнивает **элемент внутри своего трека** |
| `align` | `align-items` | `align-items` |

Множества значений не пересекаются, так что `justify="space-between"` в гриде
ловится компилятором, а не молчаливым отсутствием стиля. Распределение самих
треков по главной оси — это `justify-content`; в API оно не вынесено, потому
что в репозитории нет ни одного места, которое его задаёт.

Дефолт `justify` — `stretch`, а не `start`: начальное значение `justify-items`
— `legacy`, которое для сетки вычисляется в `stretch`.

## Шаблоны колонок

`columns` числом даёт равные треки. Строкой — любой шаблон, который понимает
CSS: треки бывают `fr` (доля свободного места), `auto` (по содержимому),
`minmax()` (границы), фиксированными длинами. Строки из репозитория:

| Разметка | Шаблон |
|---|---|
| `popover.style.ts:39` | `18px 1fr auto` |
| `Matching.style.ts:11` | `1fr auto 1fr auto` |
| `TrueFalse.style.ts:5` | `1fr 1fr` |
| `HomeShellNav.style.ts:116` | `repeat(4, 1fr)` |
| `ColorPairPicker.style.ts:146` | `repeat(10, minmax(0, 1fr))` |

## `min`: упаковка вместо счёта

`min` не задаёт число колонок, а упаковывает их: треков столько, сколько
влезает в ширину контейнера. Отсюда два следствия.

**Считает от ширины контейнера, а не окна.** `auto-fit` — механизм
`auto-fill`/`auto-fit`, а не медиазапрос, поэтому никакого `@media` в API нет и
не требуется: вложенный в `Container size="read"` грид считает от 760px, а не
от ширины окна.

**Потолка сверху нет.** `auto-fit` схлопывает пустые треки, поэтому одна
карточка растягивается на всю ширину, а на широкой области колонок становится
больше, чем на узкой. Для коллекций, которым нужно ровно N колонок, берётся
`columns`.

`min` — строка CSS-длины, а не `theme.spacing`: минимальная ширина трека это
размер содержимого, а не отступ. При базовом шаге `0.125rem = 2px` значение
`420px` равно 210 шагам — целое, но нечитаемое.

`min` побеждает `columns`, если переданы оба: упаковка — более конкретное
намерение. Вместе эти пропсы в разметке не встречаются.

## Прочее

- **`gap` в гриде ставит обе оси.** Одно свойство `gap` — это `row-gap` плюс
  `column-gap`, поэтому раздельных значений под разные оси в API нет.
- **Число колонок токеном не является.** `3` — количество, а не длина, поэтому
  `theme.layout` в этой задаче не расширялся.
- **Некорректное число колонок отбрасывается.** `repeat(0, 1fr)` — невалидное
  значение, браузер молча выбросил бы всё объявление, и компонент отдал бы
  пустую сетку. Поэтому `columns={0}` и `columns={2.5}` не дают объявления
  вовсе, а `display: grid` остаётся.

## Примеры

```tsx
// Каталог: ровно три колонки на любой ширине
<Grid columns={3} gap="lg">
  {courses.map((course) => <CourseCard key={course.id} course={course} />)}
</Grid>

// Строка пункта меню: иконка, подпись, действие
<Grid columns="18px 1fr auto" gap="sm" align="center">
  <Icon name="file" />
  <span>Переименовать</span>
  <Shortcut>⌘R</Shortcut>
</Grid>

// Галерея: колонок столько, сколько влезет
<Grid min="420px" gap="lg">
  {variants.map((variant) => <VariantCard key={variant} variant={variant} />)}
</Grid>

// Три пары «термин — определение» с зазором в базовый шаг
<Grid columns="1fr auto 1fr auto" gap={10} align="center">
  ...
</Grid>
```

## Зависимости

Импортирует `box/box.style` (нормализация блока), `base/theme` (тип
`SpacingKey`) и `base/utils` (тип `SpacingValue`). Из `primitive/`, `pattern/`
и пакетов ничего не использует.
