# Tooltip

- **Слой:** foundation
- **Файлы:** `tooltip.tsx` / `tooltip.style.ts` / `tooltip.stories.tsx`

## Назначение

Лёгкая обёртка над нативной подсказкой браузера: `content` прокидывается в
атрибут `title`. Не рисует собственную панель, не позиционируется и не
управляет состояниями — это поведение браузера.

## Когда использовать

- Нужна текстовая подсказка к кнопке-иконке или элементу без собственного
  тултип-механизма.
- Достаточно нативной подсказки (задержка, позиция, внешний вид — браузера).

## Когда НЕ использовать

- Нужна стилизованная панель с задержкой, позиционированием и управлением
  фокусом — это будущий primitive `Tooltip`/`ActionTooltip`
  (см. `theme/docs/Идеи.md`).

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `children` | `ReactNode` | — | Содержимое, к которому крепится подсказка |
| `content` | `string` | — | Текст подсказки |
| `className` | `string` | — | Класс обёртки |

## Примеры

```tsx
<Tooltip content="Удалить">
  <IconButton onClick={remove} />
</Tooltip>
```

## Зависимости

Импортирует `tooltip.style.ts`. Реакт-типы. Из других слоёв ничего
не использует.
