# Spinner

- **Слой:** foundation
- **Файлы:** `spinner.tsx` / `spinner.style.ts` / `spinner.stories.tsx`

## Назначение

Индикатор процесса загрузки: вращающийся элемент с `role="status"` и
`aria-label`. Скорость — из `theme.durations` (пара, подстроенная под
пользовательский `speed`).

## Когда использовать

- Процесс без измеримого прогресса (загрузка, ожидание).
- Состояние `loading` кнопок (через `<Spinner />` в `Button`) и подобное.

## Когда НЕ использовать

- Есть измеримый прогресс — `Progress` (foundation).

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `label` | `string` | `'Загрузка'` | `aria-label` статуса |
| `speed` | `slow \| normal \| fast` | `'normal'` | Скорость вращения (1.2s / 0.8s / 0.5s) |

## Зависимости

Импортирует `spinner.style.ts`. Из других слоёв ничего не использует.
