# ScrollArea

- **Слой:** foundation
- **Файлы:** `scrollArea.tsx` / `scrollArea.style.ts` / `scrollArea.stories.tsx`

## Назначение

Область прокрутки со стилизованным скроллбаром под тему. Прозрачная
обёртка над `<div>` — стандартные атрибуты проходят насквозь.

## Когда использовать

- Контент, которому нужна своя зона прокрутки (меню, списки, панели).
- Нужна ограниченная/максимальная высота контейнера с прокруткой.
- Зона прокрутки уже существует как `styled`-элемент со своей геометрией —
  тогда вместо обёртки берётся миксин `themedScrollbar`.

## Когда НЕ использовать

- Прокрутка всей страницы/окна — обычный document scroll.
- Нет стилизации скроллбара — обычный `<div>`.

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `height` | `string` | — | Фиксированная высота контейнера |
| `maxHeight` | `string` | — | Макс. высота: ниже — прокрутка, выше — растягивается |

Плюс все атрибуты `div`.

## Миксин themedScrollbar

`themedScrollbar` — тот же стиль скроллбара, но подмешиваемый в
`styled`-блок, который **сам** управляет `overflow`. Нужен там, где геометрия
зоны задана потребителем (`flex: 1; min-height: 0`) или прокручивается только
одна ось: `ScrollArea` жёстко ставит `overflow: auto` на обе оси.

```ts
import { themedScrollbar } from '@mai/theme'

export const Body = styled.div`
  flex: 1;
  min-height: 0;
  overflow-y: auto;
  ${themedScrollbar}
`
```

Полоса резервирует место (`scrollbar-gutter: stable`), поэтому содержимое не
прыгает вправо при появлении и исчезновении полосы.

## Примеры

```tsx
<ScrollArea maxHeight="320px">…список…</ScrollArea>
```

## Зависимости

Импортирует `scrollArea.style.ts`. Из других слоёв ничего не использует.
