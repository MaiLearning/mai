# Heading

- **Слой:** foundation
- **Файлы:** `heading.tsx` / `heading.stories.tsx`

## Назначение

Заголовок секции: композиция поверх `Text` с фиксированным семантическим
набором уровней `h1..h6`, размером, насыщенностью и цветом из токенов темы.
Дефолт — `h2`, `lg`, `semibold`, `primary`.

## Когда использовать

- Семантический заголовок блока/секции с понятным уровнем иерархии
  (`h1..h6`).
- Когда нужно ограничить текст заголовка уровнем, а не произвольным
  `Text as="…"`.

## Когда НЕ использовать

- Текст без заголовочной семантики — `Text` (foundation).
- `Heading` обеспечивает только типографику: дефолтные `color`/`size`/
  `weight` можно переопределить теми же пропсами.

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `as` | `h1 \| h2 \| h3 \| h4 \| h5 \| h6` | `'h2'` | Семантический уровень |
| `size` | `TextSize` | `'lg'` | Токен размера шрифта |
| `weight` | `TextWeight` | `'semibold'` | Насыщенность |
| `color` | `TextColor` | `'primary'` | Семантический цвет (см. Text) |

Плюс атрибуты `<h2>`. За `style`/`className` отвечает потребитель.

## Примеры

```tsx
<Heading>Заголовок секции</Heading>
<Heading as="h1" size="xl" weight="bold">Главный заголовок</Heading>
<Heading as="h3" color="muted">Подзаголовок</Heading>
```

## Зависимости

Импортирует `Text` из `foundation/text`. Собственных стилей не имеет
(композиция) — поэтому файла `.style.ts` нет.
