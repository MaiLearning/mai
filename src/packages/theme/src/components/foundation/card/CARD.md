# Card

- **Слой:** foundation
- **Файлы:** `card.tsx` / `card.style.ts` / `card.stories.tsx`

## Назначение

Базовый контейнер-поверхность карточки: фон, скругление, тень.
Содержимое (обложка, тело, футер) собирает потребитель. Поддерживает
hover-эффект для интерактивных карточек.

## Когда использовать

- Любая карточка интерфейса (сущность, превью, панель), которой нужна
  единая поверхность темы.

## Когда НЕ использовать

- Простой контейнер без визуальной карточки — `Box`/`Stack` (foundation).

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `interactive` | `boolean` | `true` | Hover-эффект (подъём + тень) |
| `as` | `article \| div \| section` | `'article'` | Семантический тег корня |

Плюс все атрибуты `div` (`onClick` и др.).

## Примеры

```tsx
<Card interactive={false}> статичная карточка </Card>
```

## Зависимости

Импортирует `card.style.ts`. Из других слоёв ничего не использует.
