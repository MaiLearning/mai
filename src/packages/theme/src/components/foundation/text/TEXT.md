# Text

- **Слой:** foundation
- **Файлы:** `text.tsx` / `text.style.ts` / `text.stories.tsx`

## Назначение

Единственная точка стилизации текста дизайн-системы: размер, насыщенность,
межстрочный интервал, выравнивание и семантический цвет — из токенов темы.
Через `as` одним компонентом закрывает заголовки, абзацы и подписи.

## Когда использовать

- Любой текст интерфейса, который должен соответствовать типографике темы.
- Заголовки уровней `h1..h6` (либо через `Text as="h2"`, либо через
  `Heading` — см. HEADING.md).

## Когда НЕ использовать

- Нужен контейнер раскладки — `Stack` / `Flex` / `Box` (foundation).
- Нужен интерактив или семантика выбора — слой `primitive/`.

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `as` | `ElementType` | `'span'` | Тег/компонент рендера, напр. `'p'`, `'h2'` |
| `size` | `xs \| sm \| md \| lg \| xl` | `'md'` | Токен `typography.sizes` |
| `weight` | `regular \| medium \| semibold \| bold` | `'regular'` | Токен `typography.weights` |
| `color` | См. примечание | `'primary'` | Семантический или произвольный CSS-цвет |
| `lineHeight` | `tight \| normal \| relaxed` | `'normal'` | Токен `typography.lineHeights` |
| `align` | `left \| center \| right \| justify` | `'inherit'` | Выравнивание |
| `ellipsis` | `boolean` | — | Одна строка с многоточием |

## Примечание о `color` (сознательное исключение)

`color` принимает и семантические ключи (`primary`, `muted`, `accent`,
`info`, `success`, `warning`, `danger`, `error`, …), которые маппятся через
`theme.utils.getText(...)`, и **любой произвольный CSS-цвет** (строку вида
`#hex`, `rgb(…)`, имя цвета). Второе — намеренный escape hatch модели
«второй источник не создаётся»: текст регулярно требуется окрасить вне
допуска шкалы до появления соответствующего токена. Это **единственное**
разрешённое место прямого CSS-цвета в foundation; новые токены при
повторяющейся потребности всё равно добавляются в шкалу.

## Примеры

```tsx
<Text as="p">Абзац</Text>
<Text as="h1" size="xl" weight="bold">Заголовок</Text>
<Text size="sm" color="muted">Подпись</Text>
<Text color="#8b91a3">Произвольный цвет</Text>
<Text ellipsis>Строка с многоточием</Text>
```

## Зависимости

Импортирует `text.style.ts` и `base/theme` (тип `AppTheme`). Ничего из
других слоёв не использует.
