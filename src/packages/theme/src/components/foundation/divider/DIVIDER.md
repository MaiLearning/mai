# Divider

- **Слой:** foundation
- **Файлы:** `divider.tsx` / `divider.style.ts` / `divider.stories.tsx`

## Назначение

Тонкая линия-разделитель между группами контента. Цвет — нейтральная
граница темы (`utils.getBorder('neutral', 'default')`), собственных
размеров и отступов не несёт: их задаёт контейнер.

## Когда использовать

- Нужно визуально разделить соседние блоки или пункты.
- Вертикальный разделитель между элементами ряда (тулбар, мета-строка).

## Когда НЕ использовать

- Нужна раскладка с зазором — `Stack` / `Flex`.
- Нужен контейнер с фоном и границей — `Card` / `Box`.

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `vertical` | `boolean` | `false` | Вертикальная ориентация (растяжка по высоте) |
| `className` | `string` | — | Для позиционирования извне |

Рендерит `role="separator"` с `aria-orientation` по пропсу.

## Примеры

```tsx
<Divider />
<Divider vertical />
```

## Зависимости

Импортирует `divider.style.ts` и `base/theme`. Из других слоёв ничего
не использует.
