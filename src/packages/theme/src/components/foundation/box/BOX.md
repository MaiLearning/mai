# Box

- **Слой:** foundation
- **Файлы:** `box.tsx` / `box.style.ts` / `box.stories.tsx`

## Назначение

Нейтральный блочный контейнер и **база всех layout-компонентов фонда**.
Правил раскладки у него нет: `Box` приводит блочную модель к масштабу
темы (`box-sizing`, сброс полей, `min-width: 0`) и служит точкой
подключения для специализаций.

Специализация = `Box` плюс одна обязанность:

| Компонент | Что добавляет к `Box` |
|---|---|
| `Container` | потолок ширины, центрирование, горизонтальные отступы |
| `Flex` | ось раскладки, выравнивание, перенос, зазор |
| `Stack` | ось раскладки и зазор |
| `Grid` | колоночная сетка, шаблон треков, зазор, выравнивание |

## Когда использовать

- Нужен блок с нормализованной блочной моделью и без собственного API.
- Нужна точка подключения для своей раскладки: `styled(Box)` наследует
  нормализацию, не дублируя её.
- Нужна подложка, которую стилизуют на месте через `style`/`className`.

## Когда НЕ использовать

- Нужна область ограниченной ширины с полями — `Container`.
- Нужна flex-раскладка — `Flex` (полный контроль) или `Stack` (ось и зазор).
- Нужна раскладка в колонки с общим выравниванием — `Grid`.
- Нужно поведение или семантика (действие, выбор, ввод) — это слой
  `primitive/` или `pattern/`.

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `as` | `div \| section \| main \| article \| header \| footer \| aside \| nav` | `'div'` | Семантический тег корня |

Плюс все атрибуты `<div>`. Собственных пропсов раскладки нет: отступы,
размеры и ось раскладки — зона специализаций.

## Примеры

```tsx
// Подложка под позиционированное содержимое
<Box style={{ position: 'absolute', inset: 0, overflow: 'auto' }}>
  {content}
</Box>

// Собственная раскладка поверх нормализованного блока
const Panel = styled(Box)`
  display: flex;
  gap: ${({ theme }) => theme.spacing.md};
`
```

## Зависимости

Импортирует только `box.style.ts`. Из `primitive/`, `pattern/` и
пакетов ничего не использует.
