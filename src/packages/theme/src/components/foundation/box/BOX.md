# Box

- **Слой:** foundation
- **Файлы:** `box.tsx` / `box.style.ts` / `box.stories.tsx`

## Назначение

Нейтральный блочный контейнер-обёртка. Не управляет раскладкой: только
приводит блочную модель к масштабу темы (`box-sizing`, сброс полей,
`min-width: 0`). Всё остальное — позиционирование, фон, размеры — задаёт
потребитель через обычные CSS-атрибуты `<div>`.

## Когда использовать

- Нужна чистая обёртка с нормализованной блочной моделью без собственных
  стилей и API.
- Блок-«подложка», которую стилизуют на месте через `style`/`className`.

## Когда НЕ использовать

- Нужна flex-раскладка — используйте `Flex` или `Stack`.
- Нужно поведение/семантика (действие, выбор, ввод) — это слой
  `primitive/` или `pattern/`.

## API

`BoxProps` — полный набор атрибутов `<div>` (`children`, `style`,
`className`, `id`, …). Собственных пропсов нет.

## Примеры

```tsx
// Обёртка с локальным позиционированием
<Box style={{ position: 'absolute', inset: 0, overflow: 'auto' }}>
  {content}
</Box>

// Произвольный контент
<Box>
  <Text>Может содержать что угодно</Text>
</Box>
```

## Зависимости

Импортирует только `box.style.ts`. Ничего из других слоёв не использует.
