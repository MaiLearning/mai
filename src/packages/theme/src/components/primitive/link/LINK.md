# Link

- **Слой:** primitive
- **Файлы:** `link.tsx` / `link.style.ts` / `link.stories.tsx`

## Назначение

Ссылка навигации: акцентный цвет, режим подчёркивания. Внешние ссылки
автоматически получают `target="_blank"` + `rel="noreferrer"`.

## Когда использовать

- Переход к другому адресу/ресурсу (навигация).

## Когда НЕ использовать

- Действие без навигации — `Button` (primitive).

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `color` | `TextColor` | `'accent'` | Семантический цвет текста |
| `underline` | `always \| hover \| none` | `'hover'` | Режим подчёркивания |

Плюс все атрибуты `a` (`href` и др.).

## Зависимости

Использует типы `foundation/text` (`TextColor`), `link.style.ts`.
