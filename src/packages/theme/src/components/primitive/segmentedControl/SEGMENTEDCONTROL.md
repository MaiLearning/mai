# SegmentedControl

- **Слой:** primitive
- **Файлы:** `segmentedControl.tsx` / `segmentedControl.style.ts` / `segmentedControl.stories.tsx`

## Назначение

Сегментированный переключатель: выбор одного из 2–4 вариантов фикс-списком
(`radiogroup`). Активный сегмент — подложка выбранного состояния + акцентная
граница.

## Когда использовать

- Взаимоисключающий выбор из маленького фиксированного набора (вид, сортировка,
  язык и т.п.).

## Когда НЕ использовать

- Много вариантов / свободное значение — `Select` (пакет `@mai/select`).
- boolean-выбор — `Checkbox`/`Switch`.

## API

| Пропс | Тип | Описание |
|---|---|---|
| `value` | `string` (обязателен) | Выбранное значение |
| `onChange` | `(value: string) => void` (обязателен) | Выбор |
| `items` | `readonly {value,label}[]` (обязателен) | Варианты |
| `disabled` | `boolean` | Блокировка |
| `id`, `aria-label`, `className` | `string` | Связь/доступность/класс |

## Зависимости

Импортирует `segmentedControl.style.ts`. Из других слоёв ничего не использует.
