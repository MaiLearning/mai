# primitive/

Слой **самодостаточных UI-абстракций**. В отличие от foundation, примитив
решает одну **интерактивную или визуальную задачу пользователя**.

Примитив уже обладает полноценным набором свойств:

- собственным **поведением** и **состоянием**;
- **accessibility** (роли, aria-атрибуты);
- **keyboard interaction** и management фокуса;
- определённой **структурой** и **API для композиции**.

## Пример

```tsx
<Button
  variant="primary"
  size="md"
>
  Save
</Button>
```

`Button` знает о действии (click, disabled, loading), о своём состоянии и
о том, как принимать фокус.

## Главное отличие от foundation

- **foundation** = generic UI infrastructure: механизм, не знающий о
  пользовательских действиях.
- **primitive** = semantic UI behavior: полноценное интерактивное и/или
  визуальное представление, которое уже решает задачу.

Примитив может быть самодостаточным представлением сам по себе — ему не
нужен контекст извне.

## Как это связано с остальными слоями

- **`foundation/`** — база системы: раскладка, типографика, обёртки.
  Примитив создаётся самостоятельно или на механизмах фундамента.
- **`pattern/`** — примитивы выступают строительными блоками паттернов:
  композиция элементов `foundation/` и/или примитивов даёт устойчивую
  переиспользуемую структуру. Паттерн может быть источником контракта
  для примитивов-участников: контролы читают контракт из паттерна
  (например контракт `Control` живёт в `pattern/field`).
- **`component/`** (внешний пакет) — примитивы входят в состав законченных
  компонентов системы.

Зависимости строятся вокруг базы, а не вертикальной цепочки —
ограничений на «примитив → паттерн» нет. Инварианты модели: граф импортов
ацикличен; `foundation/` не импортирует из верхних слоёв; примитивы не
зависят от внешних component-пакетов.

## Что сюда относится

Перенесено из `src/ui/`:

- интерактив: `Button`, `Checkbox`, `Switch`, `Link`, `Modal`,
  `SegmentedControl`;
- семантическая коммуникация: `Alert`;
- всплывающие панели: `usePopover` + `popover.style` (инфраструктура попапов,
  используются `Select`/`DropdownMenu`/`ContextMenu`).

Новые примитивы (не из `src/ui/`, добавлены в ходе миграции):

- `Input` — контрол ввода одной строки с группами startContent/endContent;
  из него собраны поля `ui/fields/`.

Не перенесено — остаются в легаси `src/ui/` (component-сценарий, вне
слоя primitive):

- `Select`, `DropdownMenu`, `ContextMenu`, `List` — ожидают слоя
  `component/` (или оставлены по решению: `List` нужен для `HierarchicalList`).
