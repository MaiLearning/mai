# Alert

- **Слой:** primitive
- **Файлы:** `alert.tsx` / `alert.style.ts` / `alert.stories.tsx`

## Назначение

Семантическое сообщение пользователю (ошибка/предупреждение/успех/
информация) с `role="alert"` и тематической иконкой варианта из глифов.

## Когда использовать

- Коммуникация результата/статуса пользователю в контенте (не тост).

## Когда НЕ использовать

- Компактная маркировка — `Badge` (foundation).
- Всплывающее уведомление — тосты `@mai/notifications`.

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `children` | `ReactNode` (обязателен) | — | Текст/контент сообщения |
| `variant` | `error \| warning \| info \| success` | `'info'` | Тип сообщения |
| `icon` | `ReactNode` | — | Своя иконка вместо тематической |
| `hideIcon` | `boolean` | `false` | Скрыть иконку варианта |

Плюс все атрибуты `div`.

## Зависимости

Использует `@mai/icons` (`Icon` и глифы `error/info/success/warning`).
Потребляется `base/gallery`.
