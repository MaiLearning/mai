# PageHeader

- **Слой:** pattern
- **Файлы:** `pageHeader.tsx` / `pageHeader.style.ts` / `pageHeader.stories.tsx`

## Назначение

Шапка раздела страницы: необязательные хлебные крошки, заголовок, описание и
правый верхний слот (поиск, действия). Задаёт вертикальный ритм и разделитель
до контента.

Текстовый блок растёт на всю свободную ширину, поэтому слот `actions` стоит
в правом верхнем углу и не съезжает под описание, пока строка помещается. На
узкой ширине ряд переносится — тогда слот уходит под текст.

## Когда использовать

- Начало раздела/страницы: заголовок + пояснение и, при необходимости, поиск
  или действия в правом верхнем углу.
- Нужен единый ритм шапки на разных страницах.

## Когда НЕ использовать

- Простой заголовок внутри карточки — `Heading` + `Text`.
- Шапка с модальной логикой (закрытие, вкладки-состояние) — собирается потребителем.

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `title` | `ReactNode` | — | Заголовок раздела (обязателен) |
| `description` | `ReactNode` | — | Пояснение под заголовком |
| `breadcrumbs` | `ReactNode` | — | Крошки над заголовком (обычно `Breadcrumbs`) |
| `actions` | `ReactNode` | — | Правый верхний слот |
| `titleAs` | `HeadingLevel` | `'h2'` | Семантический уровень заголовка |
| `className` | `string` | — | Класс корня |

## Примеры

```tsx
<PageHeader
  title="Общие"
  description="Внешний вид и язык интерфейса."
  breadcrumbs={<Breadcrumbs items={[{ label: 'Настройки', href: '/settings' }, { label: 'Общие', current: true }]} />}
  actions={<SearchInput />}
/>
```

## Зависимости

Использует `Heading` и `Text` (foundation). Крошки и слот действий приходят
готовыми узлами (обычно `Breadcrumbs`). Собственных цветов не задаёт.
