# pattern/

**Паттерны** — слой устойчивых композиций.

Паттерн — это композиция элементов `primitive/` и/или `foundation/`, которая
сама по себе полезна, но ещё **не обязательно является конечным продуктом**.
Он предоставляет **структуру и инфраструктуру**, которую можно применять к
разным контекстам и контролам, и отличается **нестандартизированным API**:
у паттерна своя форма, а не только набор пропсов примитива.

## Пример: Field

`Field` — полноценный паттерн. Это семантический контейнер одного элемента
данных формы: подпись (`Field.Label`), описание (`Field.Description`),
ошибки (`Field.Error` + `Field.ErrorMessage`), счётчик (`Field.Counter`).
Контролы (`Input`, `Textarea`, `Checkbox` и прочие) участвуют через контракт
`useFieldControl`, определённый в `pattern/field`. Сам по себе паттерн не
является конечным продуктом — для этого существует слой пакетов: поля
(`TextField`, `NumberField`, …) реализуются **на основе** паттерна в
`@mai/fields`.

## Как это связано с остальными слоями

- **Фонд** — нижележащие механизмы, на которых собрана инфраструктура
  паттерна.
- **Примитивы** — строительные блоки паттерна: он комбинирует элементы фонда
  и/или примитивы в устойчивую конструкцию со своим API. Паттерн может быть
  источником контракта для примитивов-участников: контролы читают контракт
  из паттерна (например контракт `Control` живёт в `pattern/field`).
- **Пакеты** — паттерн служит основой для конечных продуктов: `TextField`,
  `NumberField` и прочие реализуются **на основе** паттернов и примитивов.

Компоненты темы не зависят от продуктовых пакетов: паттерн не знает о
конкретных конечных продуктах. Граф импортов ацикличен.

## Что сюда относится

- `Field` — структура «подпись + контрол + сообщение»;
- `CheckboxGroup` — композиция `Checkbox` + текстовая подпись;
- `Breadcrumbs` — цепочка пути из ссылок/текстовых крошек и разделителей;
- `NavList` — навигационный список с группами, иконками и вложенными
  пунктами;
- `PageHeader` — шапка раздела (крошки + заголовок + описание + слот
  действий).

У каждого паттерна — собственная заметка `*NAME*.md` в его директории.
