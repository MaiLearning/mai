# pattern/

Слой **устойчивых композиций примитивов**.

Паттерн — это композиция нескольких `primitive/`, которая сама по себе
полезна, но ещё **не обязательно является конечным компонентом**. Он
предоставляет **структуру и инфраструктуру**, которую можно применять к
разным контекстам и контролам.

## Пример: Field

`Field` — полноценный паттерн. Это семантический контейнер одного элемента
данных формы: подпись (`Field.Label`), описание (`Field.Description`),
ошибки (`Field.Error` + `Field.ErrorMessage`), счётчик (`Field.Counter`).
Контролы (`Input`, `Textarea`, `Checkbox` и прочие) участвуют через
контракт `useFieldControl`, определённый в `pattern/field`. Сам по себе
паттерн не является конечным компонентом — для этого существует слой
`component/`.

## Как это связано с остальными слоями

- **`foundation/`** — нижележащие механизмы, на которых собрана
  инфраструктура паттерна.
- **`primitive/`** — строительные блоки паттерна: он комбинирует элементы
  `foundation/` и/или примитивы в устойчивую конструкцию со своим API.
  Паттерн может быть источником контракта для примитивов-участников:
  контролы читают контракт из паттерна (например контракт `Control` живёт
  в `pattern/field`).
- **`component/`** (внешний пакет) — паттерн служит основой для конечных
  компонентов: `TextField`, `DateField` и прочие реализуются **на основе**
  паттернов и примитивов.

Слои темы не зависят от внешних component-пакетов: паттерн не знает о
конкретных конечных продуктах. Граф импортов ацикличен.

## Что сюда относится

Перенесено из `src/ui/`:

- `Field` — структура «подпись + контрол + сообщение»;
- `CheckboxGroup` — композиция `Checkbox` + текстовая подпись.

Добавлены в ходе разработки:

- `Breadcrumbs` — цепочка пути из ссылок/текстовых крошек и разделителей;
- `NavList` — навигационный список с группами, иконками и вложенными пунктами;
- `PageHeader` — шапка раздела (крошки + заголовок + описание + слот действий).

Не перенесено — остаётся в легаси `src/ui/`:

- `HierarchicalList` — композиция `List` с раскрытием/сворачиванием
  и общей selection-моделью (в экспериментальном статусе, оставлено по
  решению).
