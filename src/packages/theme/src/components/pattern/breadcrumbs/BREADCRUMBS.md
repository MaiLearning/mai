# Breadcrumbs

- **Слой:** pattern
- **Файлы:** `breadcrumbs.tsx` / `breadcrumbs.style.ts` / `breadcrumbs.stories.tsx`

## Назначение

Навигационная цепочка пути от старшего предка к текущему элементу. Показывает,
где находится пользователь и как вернуться назад. Состоит из ссылок (`Link`),
текстовых или кнопочных крошек и разделителей между ними.

## Когда использовать

- Шапка раздела/ресурса: «Курс / Модуль / Тема», «Настройки / Общие».
- Нужна навигация назад по иерархии с явным указанием текущего элемента.

## Когда НЕ использовать

- Верхнеуровневая навигация приложения — `NavList` или боковое меню.
- Одно значение без иерархии — обычный `Text`/`Heading`.

## API

| Пропс | Тип | Дефолт | Описание |
|---|---|---|---|
| `items` | `readonly BreadcrumbItem[]` | — | Цепочка крошек (обязательна) |
| `separator` | `ReactNode` | шеврон | Разделитель между крошками |
| `maxItems` | `number` | — | Свёртка длинной цепочки: первый + последние `maxItems - 2` (меньше 3 — без свёртки) |
| `ariaLabel` | `string` | — | Доступное имя навигации |
| `className` | `string` | — | Класс корня |

`BreadcrumbItem`: `{ label: string; href?: string; onClick?: () => void; current?: boolean }`.
Если у элемента нет `href`/`onClick`, он рендерится текстом. Последний элемент
считается текущим, если `current` не задан явно; текущий получает `aria-current="page"`.

## Примеры

```tsx
<Breadcrumbs
  ariaLabel="Путь"
  items={[
    { label: 'Курс', href: '/course/1' },
    { label: 'Общие', current: true },
  ]}
/>

// Свёрнутая длинная цепочка
<Breadcrumbs maxItems={2} items={items} />
```

## Зависимости

Использует `Link` (primitive), `@mai/icons` (`ChevronRightIcon`) и токены темы.
Собственных цветов не задаёт — только `theme.utils.*`.
