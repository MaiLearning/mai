## Components

На данный момент существуют следующие UI компоненты:
- `base` - базовый набор компонентов, на основе которого выстраивается интерфейс, а так же создаются более сложные компоненты
- `date` - компоненты связанные с датами, отображение календарей, ввод данных связанных с временем.
- `icons` - набор иконок приложения, использует в своей основе компонент 
- `List` — управляемая одноуровневая коллекция. Направление задаётся через
  `direction` (`vertical`/`horizontal`), расстояние между элементами — через
  `gap` (токен spacing или CSS-значение).

## Experimental

Это компоненты которые находятся в экспирементальном режиме, в разработке, и пока они в данном статусе - их использование в иных пакетах запрещено!

- `HierarchicalList` — иерархическая коллекция на основе `List` и `List.Item`.
  Используется композиционно через `HierarchicalList.Item` с обязательным
  `value` и произвольными `children`. Поддерживает централизованное раскрытие,
  общую selection-модель и навигацию стрелками `Left`/`Right`. Для массивов
  данных доступна необязательная утилита `renderHierarchicalItems`.
